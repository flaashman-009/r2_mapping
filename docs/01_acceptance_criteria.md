# 验收标准

分两级：**Gate A 前置条件**（不满足不许开建图）和 **Gate B 交付物**。

---

## Gate A — 前置条件（缺一不可）

用 `./scripts/check_all.sh` 自动检查，人工确认项单独标注。

### A1. 传感器 `/scan`

| 指标 | 合格 | 警告 | 失败 |
|---|---|---|---|
| 频率 | 8–12 Hz | 6–8 或 12–15 Hz | < 6 Hz 或断流 |
| 数据有效性 | 量程内无成片 NaN/Inf | 少量 NaN | 整帧无效 |
| 帧号 | 连续递增无回退 | 偶发回退 | 频繁回退 |

### A2. 里程计 `/odom_raw`

| 指标 | 合格 | 警告 | 失败 |
|---|---|---|---|
| 频率 | 8–12 Hz | 5–8 Hz | < 5 Hz |
| 连续性 | 相邻帧位移与速度自洽 | 偶发跳变 | 单帧跳变 > 0.5 m |
| 方向 | 前进时 `x` 单调增，后退时单调减 | 有偏置 | 符号相反 |
| 标尺 | 实走 1 m 误差 < 5% | 5–10% | > 10% |

方向与标尺由人工确认（车头朝前、直行 1 m 对比卷尺），工具只报数据。

### A3. IMU

| 指标 | 合格 | 警告 | 失败 |
|---|---|---|---|
| `/imu/data_raw` 频率 | 8–12 Hz | 5–8 Hz | < 5 Hz |
| 静止角速度 | \|ω\| < 0.02 rad/s | < 0.05 | > 0.05 |
| `/imu/yaw_deg` 跳变 | 无 ±180° 跳变 | 偶发 | 频繁跳变 |
| 静止 60 s 漂移 | < 1° | < 3° | > 3° |

### A4. TF 树

必须能查询到完整链路（`tf2_echo` 或自检工具通过）：

```
map -> odom -> base_footprint -> base_link -> laser
                                base_link  -> imu_link
```

| 指标 | 合格 | 失败 |
|---|---|---|
| 建图时 `odom→base_link→laser` | 可查，延迟 < 0.2 s | 查不到 / 延迟 > 0.5 s |
| 定位时 `map→odom` | 可查（由 AMCL 发布） | 查不到 |
| 全链路 `map→laser` | 可查 | 查不到 |

> 注：部分原厂 URDF 用 `base_footprint` 作为根，部分用 `base_link`。
> 自检工具两种都接受，只要链路端点连通即可。

### A5. 时间同步

以最新帧时间戳互差为准：

| 指标 | 合格 | 警告 | 失败 |
|---|---|---|---|
| `/scan` 与 `/odom_raw` | < 50 ms | 50–200 ms | > 200 ms |
| `/scan` 与 `/imu/data_raw` | < 50 ms | 50–200 ms | > 200 ms |
| 消息年龄（now − stamp） | < 0.2 s | 0.2–1.0 s | > 1.0 s |

### A6. 外参

| 指标 | 合格 |
|---|---|
| LiDAR 相对 `base_link` 的 x/y/z/yaw | 已写入并验证（`docs/03_tf_and_extrinsics.md`） |
| 验证方法 | 车头对墙、旋转 90° 两次，墙线在 RViz 中位置一致 |
| 残余误差 | 静止对墙时墙面偏差 < 0.05 m，角度偏差 < 2° |

## Gate B — 交付物

### B1. 可加载的地图

| 项 | 要求 |
|---|---|
| 文件 | `maps/<name>.pgm` + `maps/<name>.yaml`（同名） |
| 分辨率 | 0.05 m/cell（`slam_toolbox` 与本项目 PCD 工具默认一致） |
| `mode` | `trinary` |
| `origin` | 与 PGM 尺寸自洽 |
| `negate` | 0 |
| `occupied_thresh` / `free_thresh` | 0.65 / **0.196**（见下方说明） |
| 比例 | unknown 区域主要出现在未走过的边角，不是地图主体 |
| 墙线 | 厚度 1–2 格（0.05–0.10 m），无大面积毛刺 |
| 加载验证 | `ros2 run nav2_map_server map_server --ros-args -p yaml_filename:=...` 能起 lifecycle |

### ⚠️ 关于 `free_thresh`（踩过的坑）

ROS 地图的三个约定灰度是 `0 = occupied`、`254 = free`、`205 = unknown`。
其中 205 对应的占据概率是 `(255 − 205) / 255 = 0.196`。

所以只要 `free_thresh > 0.196`（例如很多模板里的 0.25），
**所有 unknown 格都会被判成 free**，地图上会凭空多出一大片"可通行区域"，
unknown 比例统计也会永远是 0%。

在本项目的历史地图 `environment_final.yaml`（`free_thresh: 0.25`）上实测：

| 统计口径 | unknown 占比 |
|---|---|
| 按 YAML 阈值分类 | 0.0% |
| 按原始灰度 205 统计 | **76.7%** |

结论：**`free_thresh` 用 0.196**，并且判定 unknown 比例时要看原始灰度
（`map_eval.py` 会同时给出两个数字并给出警告）。

用 `./scripts/map_eval.sh maps/<name>.yaml` 出统计报表。

### B2. 闭环一致性

| 指标 | 合格 | 警告 | 失败 |
|---|---|---|---|
| 回到起点时地图重合 | 重影 < 2 格（0.1 m） | 2–4 格 | > 4 格，或墙体分叉 |
| 重复经过同一走廊的墙线 | 单线 | 轻微双线 | 明显双线 / 扭曲 |

### B3. AMCL 定位复测

| 指标 | 合格 | 失败 |
|---|---|---|
| AMCL 收敛 | 初始位姿设置后 10 s 内 `/amcl_pose` 协方差收敛 | 长期不收敛 |
| 定位精度 | 静止时与实车位置偏差 < 0.15 m、< 5° | > 0.3 m 或持续漂移 |
| TF 一致性 | `map→laser` 在 RViz 中与实车朝向一致 | 明显错位 / 抖动 |
| 移动复测 | 沿走廊走 10 m 后回到起点，位置偏差 < 0.2 m | 明显漂移 |

### B4. 数据留档

- `bags/` 至少留一份完整建图过程的 bag（`scripts/record_bag.sh`）。
- `docs/06_test_log.md` 每次上车追加一条记录。
- 地图、bag、日志与当次参数配套，能事后复现。
